# Portfolio_Chinmay

A modern, responsive full-stack developer portfolio showcasing projects and skills built with the MERN stack and beyond.

## Live Demo

🔗 [View Portfolio](https://sypher08.github.io/Portfolio_Chinmay/)

## About

This is my personal portfolio website — a single-page application featuring smooth scroll animations, interactive elements, and a clean, dark-themed UI. Built entirely with vanilla HTML, CSS, and JavaScript, with no frameworks or dependencies.

## Tech Stack

- **HTML5** — Semantic markup and structure
- **CSS3** — Custom properties, flexbox, grid, animations, and responsive design
- **JavaScript (ES6+)** — Intersection Observer API, event handling, and DOM manipulation

## Features

- Responsive design for mobile and desktop
- Smooth scroll-triggered reveal animations
- Interactive tilt effect on the hero code window
- Custom cursor glow effect
- Mobile hamburger menu
- Project modal system
- PDF resume download

## Projects Featured

1. **Urban Intel Platform** — Smart-city data visualization platform (React.js, Node.js/Express.js, MongoDB)
2. **Online Cloud Kitchen Platform** — E-commerce app with MySQL backend and Postman-tested APIs
3. **Gibberlink AI** — Python automation utility with a JavaScript UI
